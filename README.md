# Практична робота №1 — Основи мови TypeScript

## Мета роботи

Навчитись складати елементарні функції та алгоритми мовою TypeScript.

## Виконані завдання

**1.1. Базові типи**
- Створено інтерфейс `Worker`.
- Реалізовано функції `getAllWorkers()` та `logFirstAvailable()`.
- Використано базові типи, цикл `for...of` та шаблонні рядки.

**1.2. Робота з Enum і фільтрацією**
- Створено перелічення `Category`.
- Реалізовано функції `getWorkersSurnamesByCategory()` і `logWorkersNames()`.
- Реалізовано пошук працівників за категорією.

**1.3. Стрілочні функції**
- Додано ідентифікатори працівників.
- Використано `forEach` та стрілочні функції.
- Реалізовано `getWorkerByID()` із використанням методу `find()`.

**1.4. Типи функцій**
- Створено функцію `createCustomerID()`.
- Оголошено змінні `myID` та `idGenerator`.
- Продемонстровано типізацію функцій та використання стрілочних функцій.

**1.5. Необхідні, додаткові та залишкові параметри**
- Реалізовано функцію `createCustomer()`.
- Використано необов'язкові параметри та параметри за замовчуванням.
- Реалізовано функцію `checkoutWorkers()` із залишковими параметрами.
- Додано перевірку доступності працівників.

## Структура проєкту

- `src/index.ts` — головний файл запуску та демонстрація функцій.
- `src/types.ts` — інтерфейс `Worker` і перелічення `Category`.
- `src/workers.ts` — функції роботи з працівниками.
- `src/customers.ts` — функції роботи із замовниками.
- `tsconfig.json` — конфігурація TypeScript.
- `package.json` — залежності та команди запуску.
- `.gitignore` — перелік файлів і папок, які ігнорує Git.

## Використані технології

- WebStorm
- Git та GitHub

## Інструкція запуску

Для запуску проєкту необхідно встановити Node.js та npm.

1. Завантажити репозиторій на комп'ютер.
2. Відкрити папку проєкту в терміналі.
3. Виконати `npm install` для встановлення залежностей.
4. Виконати `npm run start` для компіляції та запуску програми.

Для окремої компіляції TypeScript використовується команда `npm run build`.
